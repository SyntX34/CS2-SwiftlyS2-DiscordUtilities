# Contributing to Discord Utilities

Thanks for your interest in contributing to **Discord Utilities**!

## Getting Started

1. Fork the repository and clone your fork.
2. Create a new branch for your feature or fix (`git checkout -b feat/your-feature`).
3. Make sure you have the .NET SDK and SwiftlyS2 dependencies available to build the project (`dotnet build`).

## Code & Style Guidelines

- Follow the existing partial-class module structure under `src/Features/` and configuration models under `src/Config/PluginConfig.cs`.
- Keep changes focused on a single feature or fix.
- Verify the project compiles cleanly before opening a pull request.

## Pull Requests

1. Update `README.md` if you add or change user-facing features or configuration options.
2. Use clear, descriptive commit messages.
3. Open a pull request against `main` describing what changed and why.
