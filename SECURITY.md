# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| < 1.1.0 | No        |

## Reporting a Vulnerability

If you discover a security vulnerability (for example, token exposure, permission bypass, or RCON authorization issues), please do **not** open a public issue.

Instead, report it privately to the repository maintainers via GitHub Security Advisories or direct contact so it can be investigated and patched before public disclosure.
